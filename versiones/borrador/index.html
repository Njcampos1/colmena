La colmena que se apaga

Cada trimestre, los apicultores de EE.UU. pierden entre el 8 % y el 18 % de sus colonias. Y en todos los trimestres la amenaza más frecuente es la misma: el ácaro varroa. Escucha cómo la colmena se debilita cuando las amenazas aumentan.

Pero la colmena no se apaga del todo

Aunque se pierde una de cada siete colonias por trimestre, el total casi no cambia: los apicultores dividen colmenas y compran reinas para reponerlas. Las abejas silvestres sufren las mismas amenazas (pesticidas, parásitos, clima), pero nadie las repone.
